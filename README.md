# About OrionClient
OrionClient is a reliable, functional, and feature-rich client system for [roturTW](https://rotur.dev/).

## Key features
- Built in pure HTML, CSS, JS. No external dependencies, promising unmatched reliability.
- Powerful one-of-its-kind features like credit dashboards, sidebar applications, and more.
- Focuses on ensuring optimal network and memory load for both the client and the server.
- Orion is based on Nova.CSS, and has features like themes and a collection of Rotur Apps, which were moved here from [NovaOS](https://github.com/runnova/NovaOS).

## OrionClient exists for user control
- OrionClient is one of the most well-integrated and community-driven Rotur clients.
- While we adhere to its policy, Rotur has no control over how OrionClient implements features.
- By providing an alternate UI that tells users what they are enabling, even by subtle but intuitive UX clues.
